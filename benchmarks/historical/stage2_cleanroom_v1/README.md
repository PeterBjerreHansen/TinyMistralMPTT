# Stage 2 clean-room results

This directory retains the result reports from the historical 512-token
clean-room campaign. The runnable configs, checkpoints, generated run
directories, and data recipe were intentionally removed when the 2048-token
qualification became the active pre-lock setup.

The result reports record the relevant learning rates, token budgets, pass
weights, validation measurements, and historical interpretation. New work
should use the appropriate directory under `benchmarks/`.
